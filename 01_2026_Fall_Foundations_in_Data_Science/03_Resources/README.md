# Resources: HSE 711: Foundations in Data Science



References, cheat sheets, and links I found useful for HSE 711: Foundations in Data Science, Fall 2026.



## Cheat sheets

* \[Unix/Linux Command Reference](https://docs.rcc.fsu.edu/hpc/cheat-sheets/linux-bash-cheat-sheet.pdf): This resource includes commands for file commands, process management, file permissions, SSH, searching, system info, compression, network, installation, and other shortcuts.



## Helpful links

* \[Complex Heatmap Tutorial: Create publication-ready heatmaps in R](https://biostatsquid.com/heatmaps-with-complexheatmap-r-tutorial/): This resource teaches you how to create and customise a heatmap with R package ComplexHeatmap.
* \[Anscombe's quartet](https://en.wikipedia.org/wiki/Anscombe%27s\_quartet): This resource explains four small datasets with nearly identical summary statistics (mean, variance, correlation, regression line) that look completely different when graphed. It's a classic reminder to always plot your data before trusting the numbers.
* \[r-statistics.co](https://r-statistics.co/): This resource includes free tutorials for doing statistics and machine learning in R, from regression and statistical tests to ggplot2 charts, with example code you can copy and run.
* \[ggplot2 Data Visualization Cheatsheet](https://rstudio.github.io/cheatsheets/html/data-visualization.html): This resource includes posit's quick reference for building charts in R with ggplot2, covering geoms, aesthetics, scales, facets, themes, and labels on one page.
* \[ColorBrewer: Color Advice for Maps](https://colorbrewer2.org/#type=sequential\&scheme=BuGn\&n=3): This resource includes a tool for choosing color palettes for maps and charts, with sequential, diverging, and qualitative schemes plus filters for colorblind-safe and print-friendly options. The same palettes are built into R through `RColorBrewer` and ggplot2's `scale\_fill\_brewer()`.
* \[The R Graph Gallery](https://r-graph-gallery.com/): This resource contains hundreds of R chart examples sorted by chart type, each with reproducible ggplot2 or base R code, so you can find a visual you like and adapt the code.
* \[ggplot2 extensions](https://www.ggplot2-exts.org/): This resource lists add-on packages that extend ggplot2 with new chart types, themes, animations, and layout tools, with a short preview of what each one does.
* \[TCGA Barcode - GDC Docs](https://docs.gdc.cancer.gov/Encyclopedia/pages/TCGA\_Barcode/): This resource details how to read The Cancer Genome Atlas (TCGA) barcodes, breaking down each segment (project, tissue source site, participant, sample type, vial, portion, analyte, plate, and center) so you can identify and match samples across datasets.
