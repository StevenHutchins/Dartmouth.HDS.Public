## Helpful links

* \[R programming for ABSOLUTE beginners](https://www.youtube.com/watch?v=FY8BISK5DpM): R programming for beginners is meant to introduce you to R programming without the stress. Using R for statistical analysis and data science is becoming increasingly popular. At first, using R and R studio might seem a little intimidating. Watch this video and you'll find that it's not that hard at all. This is a very gentle introduction to R programming.
* \[What is R Markdown?](https://www.youtube.com/watch?v=asHhuHRxhvo): R Markdown is an easy way to generate reports that incorporate both R code and lightly-formatted text.
* \[Intuitive Biostatistics](https://global.oup.com/ushe/product/intuitive-biostatistics-9780190643591?q=Intuitive%20Biostatistics:%20A%20Nonmathematical%20Guide%20to%20Statistical%20Thinking&cc=gb&lang=en): This is one of the professors favorite biostatistics texts. It is not a traditional textbook. Instead, it is a commentary on foundational, applied biostatistical methods. The author simplifies common methods and includes limitations of those methods. This course includes two chapters from this text.
* \[The NIST/SEMATECH Engineering Statistics Handbook](https://www.itl.nist.gov/div898/handbook/): This is an open-source, applied statistics handbook. The text is easy to read and includes complete information on probability distributions and statistics equations. The class will refer to this resources several times.
* \[Bernard Rosner. Fundamentals of Biostatistics. Cengage Learning. 8th edition](https://www.cengage.com/c/fundamentals-of-biostatistics-8e-rosner/9781305268920/?searchIsbn=9781305268920): This text is a well validated and trusted source of information, and students may likely continue to use the text into the future. The text is available in print or as an e-book; the e-book can also be rented directly from Cengage.
