# Online MS in Health Data Science - Dartmouth Geisel School of Medicine, 2026-2028



Hello world! My name is Steven Hutchins and I'm working on my online MS in Health Data Science at Dartmouth Geisel School of Medicine.



## How this repo is organized

Each course has it's own folder, named by sequential course order, year, term, and course name. 

- `01_2026_Fall_Foundations_in_data_science`

Inside every course folder:
- `01_LectureNotes/`: weekly notes from lectures and readings
- `02_Projects/`: projects and practice work
- `03_Resources/`: references, cheat sheets, and links
- `04_Final/`: the final project for the course
